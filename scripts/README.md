# Utility & Automation Scripts

This directory is designated for standalone utility scripts supporting the simulation environment.

## Planned Scripts
- `generate_random_map.py`: Generates randomized grid maps with variable obstacle densities and connectivity guarantees.
- `benchmark_planners.py`: Automated batch execution comparing A* and Dijkstra across varied obstacle layouts.
- `run_headless.py`: Runs simulation episodes without Pygame display rendering for rapid headless validation and metrics logging.
