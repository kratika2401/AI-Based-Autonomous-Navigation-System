## Operating Protocol
1. **Continuous Documentation:** Any code implementation, script creation, or configuration update will be synchronized with the relevant document in this folder.
2. **Implementation & Validation Reporting:** Each subsequent task execution will provide a concise status report accompanied by executable validation criteria and verification tests.
