# Interactive Prototyping & Analysis Notebooks

This directory is reserved for Jupyter notebooks used for mathematical prototyping, exploratory analysis, and algorithm visualization.

## Planned Notebooks
- `01_grid_and_coordinate_systems.ipynb`: Interactive demonstration of the 2D grid, raycasting, and coordinate conversions.
- `02_pathfinding_visualization.ipynb`: Visual comparative analysis of A* vs. Dijkstra search frontiers, expanded nodes, and path costs.
- `03_metrics_evaluation.ipynb`: Plotting trajectory error, step counts, and runtime performance benchmarks.
